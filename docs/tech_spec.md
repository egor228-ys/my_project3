\# Техническое задание (ТЗ)



\## Требования к системе

1\. Система должна обеспечивать регистрацию и авторизацию пользователей.

2\. Система должна иметь каталог книг с поиском по названию и автору.

3\. Система должна содержать корзину для формирования заказа.

4\. Система должна интегрироваться с платёжным шлюзом для оплаты.
